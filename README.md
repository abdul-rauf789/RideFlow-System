# RideFlow-System

---

**RideFlow — Ride Hailing Platform**

RideFlow is a ride-hailing platform inspired by Uber and Careem, built as a Database Systems semester project at FAST NUCES. It features a complete MySQL backend with seven interconnected modules covering user management, ride lifecycle tracking, driver and vehicle verification, fare calculation with surge pricing, promo codes, payment processing, and a mutual ratings system. The system includes stored procedures for automated fare computation, triggers for driver flagging, and role-based access control using MySQL DCL commands, paired with a live JavaScript frontend UI.

**Getting Started**

1. Open MySQL Workbench or any MySQL client
2. Run the `.sql` file first — this will create the database, all tables, stored procedures, triggers, and sample data
3. Once the database is created, open the UI/UX file in your browser
4. Make sure the database name in the UI/UX config matches exactly with the one created by the SQL file
5. You're good to go

**Tech Stack**

- Database: MySQL
- Frontend: JavaScript, HTML, CSS

**Project Structure**

- `RideFlow.sql` — full database schema, procedures, triggers, and seed data
- `RideFlow_UIUX.html` — main UI/UX frontend file
